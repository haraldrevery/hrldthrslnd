Page folder

Kept
together

A page and its media in one folder, published as a unit. Asset paths are relative to the page, so nothing has to be rewritten when the folder moves.

How the folder is published

The page becomes /post_i.html. Everything beside it — images, audio, anything else — is copied to /post_i/, so a reference like /post_i/statue.jpg resolves without any rewriting.

The slug comes from the folder name, and shares one namespace with input_markdown/ and input_custom_html/. Two inputs cannot claim the same URL — the build warns and adds a suffix.
