# What this page is for

Every block below is a run of `![alt](path)` lines written with no blank line
between them. Two or more in a row become one justified gallery; a single one
stays a captioned figure. The point of the page is the awkward cases — a run
that wraps and leaves one picture alone on the last row, a run of nothing but
portraits, a run of panoramas, a run that mixes them.

Read the heading above each block: it says what the run is, so a layout that
goes wrong is obvious rather than merely ugly.

## Two singles are two figures

## An image with text under it on the next line

This is deliberately *not* a gallery and deliberately not a figure: the
paragraph holds an image and a line of prose, so it stays a paragraph. Only a
run of nothing but images is rewritten.

The alt below contains an ampersand, quotation marks and angle brackets. They
