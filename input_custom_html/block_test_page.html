Text section, single column

Body copy sits in a .prose container, which is where all the markdown typography rules live — headings, lists, quotes, tables, code and footnotes. Inline mathematics such as χ2=∑i(Oi−Ei)2Ei\chi^2 = \sum_i \frac{(O_i - E_i)^2}{E_i}χ2=∑i​Ei​(Oi​−Ei​)2​ flows with the sentence and keeps its own metrics, independent of the body type scale.

Display mathematics gets its own block and scrolls sideways if it has to:

∫−∞∞e−x2 dx=π\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}∫−∞∞​e−x2dx=π​
A pull quote uses a gradient left border rather than a heavier weight, because these fonts have exactly one weight each.

Left column

Two-column blocks collapse to one column below the mobile breakpoint, which is defined once in css/input.css as --breakpoint-md. Nothing here sets its own breakpoint.

Right column

Any two blocks can be paired this way — text beside an image, a gallery beside a download, an FAQ beside a feature panel. Wrap them in .block-two-col and they line up.

Gallery — justified

Mixed proportions on purpose — portrait, landscape and panorama in one run, which is the arrangement this layout exists for.

FAQ

Does this work without JavaScript?
Yes. It is a native <details> element. The plus turns into a minus and the gradient fills the ring, all in CSS.
Can several be open at once?
Yes, by default. Give every <details> in a group the same name attribute if you want them to behave as an accordion where opening one closes the rest.
How long can an answer be?
As long as you like. The panel is a normal block, so lists, images and mathematics all work inside it.

Section 04 — Field notes

Jotunheimen,
from the top

Note 01 · 2469 m

The distance goes flat

Above the last ridge every peak is the same colour. Depth stops coming from tone and starts coming from where things overlap — which is a layout problem the mountains solved first.

Note 02 · Glacier

Blue is a thickness

Glacier blue is not a pigment, it is how far the light had to travel through the ice before it came back out. The same is true of every frosted panel on this page.

Note 03 · Descent

A photograph is not the walk

Eleven hours compress to one frame, and the frame keeps the view but loses the weather. The caption is where the rest of it has to go, so the caption is worth writing.
