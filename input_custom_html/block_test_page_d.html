When to reach for the salon

Variant D is for a page that wants to feel curated rather than busy: a portfolio front, a collection, a single essay with one picture worth framing. It needs the same thing variant C's collage needs — a portrait strong enough to hang — but only one of them, and nothing else. Where there is no such picture, variant A is still the better answer, and where there are six of them, see variant C.

It follows the colour scheme like the other stages do: an ivory salon in light mode, the old matte in dark. The gilded word, the mount and the stamp all move with the scheme, because every colour on the page is a token — the only inline override is which gradient the .text-flow word wears.

Compare the other treatments — I, II and III — and every other block on the block test page.

What to check

  • Both colour schemes. The stage follows the system setting; the ink-panel note deliberately does not.
  • A phone. The two voices stack — type first, portrait after it, centred — and the stamp stays on the mount's corner.
  • A short viewport. The gaps retune themselves through .hero-copy's tokens; the engraved line reserves the scroll cue's lane.
  • Reduced motion. The gilded word stops panning and stays legible on the stage.
  • Scripting off. Only the lightbox goes; the page is otherwise complete.
  • The mount in dark mode. It should read as a dark mat behind the frame, not as a second shadow — it is one panel, translated.
